# Parsec

Parsec is a collaboration-matching app built to help creators discover the right people for ambitious ideas.

## Overview

Parsec makes it easier for creators to turn bold ideas into real projects by showing who is most likely to help them build it. The app matches people based on:
- shared skills
- shared interests
- project fit
- collaboration momentum

Instead of treating project discovery as a cold job board, Parsec feels like a creative match engine for building together.

## Problem

Many creators have strong ideas, but they struggle to find the right collaborators. The challenge is not only technical expertise — it is also alignment in interest, vision, and project energy.

## Solution

Parsec lets a creator:
- create a project
- define the required skills and interests
- create a profile with their own skills and interests
- see likely matches
- review overlap and project fit
- send a connection request

## Features

- Create a project with title, description, skills, and interests
- Create and save a contributor profile
- Match profiles against a selected project
- View fit scores based on shared skills and interests

## Tech Stack

- HTML
- CSS
- JavaScript

## How It Works

1. A user creates a project.
2. They define the skill and interest needs for that project.
3. A contributor creates a profile with their own skills and interests.
4. The app compares the project with each profile.
5. It calculates a fit percentage based on overlap.
6. The creator reviews matches and sends a request.

## Run Locally

Open the project in a browser:
- open `index.html`

No installation is required for the prototype.
